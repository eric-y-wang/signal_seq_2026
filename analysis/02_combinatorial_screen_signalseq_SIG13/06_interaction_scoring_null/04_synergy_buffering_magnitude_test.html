Goal

interaction_scoring_v3.R reports that synergy is most common in genes whose expected additive effect is near zero, and buffering in genes where it is large. This notebook asks whether that pattern is stronger in the real data than in the empirical null built from the 9 non-targeting linker barcodes.

Each class is compared only with itself, real vs. null:

  • Buffering: do real buffering calls come from genes with larger |lfc_additive_expected| than null buffering calls?
  • Synergy: do real synergy calls come from genes with smaller |lfc_additive_expected| than null synergy calls?

The null shows where calls land when no biology drives them. The question is whether the real data departs from that in the predicted direction.

Quantities per gene x ligand pair, from the interaction GLM:

  • lfc_ligand1, lfc_ligand2: single-ligand coefficients
  • lfc_interaction: the ligand1:ligand2 coefficient
  • lfc_additive_expected = lfc_ligand1 + lfc_ligand2: the expected additive effect, which is the quantity under test
  • lfc_total_interaction_model = lfc_additive_expected + lfc_interaction
  • interaction_score = lfc_interaction / lfc_total_interaction_model: its sign sets the class (negative = buffering, positive = synergy)

Two corrections

A naive real vs. null comparison is confounded in two ways.

1. Percentile scale. The null has no true effects, so all of its LFCs are smaller. Real calls would sit at higher raw LFCs for that reason alone. To remove this, |lfc_additive_expected| is converted to a percentile within each source’s own gene-tests, before any selection.

2. Rate-matched selection. At adj_pval <= 0.1 the real data calls ~42x more of its gene-tests than the null does. The null’s few calls then come only from the extreme tail of its distribution, which pushes them toward percentile 1. To avoid this, both sources contribute the same fraction of gene-tests: the top hits by interaction p-value, with the fraction set to the null’s adj_pval <= 0.1 rate.

Load and derive quantities at matched filter_cutoff = 0.1

build_table <- function(interaction_file, singles_file, source_label) {
  interactionTbl <- fread(interaction_file, select = c("name", "pval", "adj_pval", "lfc", "interaction")) %>%
    as_tibble() %>%
    rename(lfc_interaction = lfc, adj_pval_interaction = adj_pval, pval_interaction = pval)

  singlesTbl <- fread(singles_file, select = c("name", "lfc", "interaction", "single_ligand")) %>%
    as_tibble() %>%
    mutate(ligand_slot = if_else(grepl("_round1$", single_ligand), "lfc_ligand1", "lfc_ligand2")) %>%
    select(name, interaction, ligand_slot, lfc) %>%
    pivot_wider(names_from = ligand_slot, values_from = lfc)

  interactionTbl %>%
    inner_join(singlesTbl, by = c("name", "interaction")) %>%
    mutate(
      lfc_additive_expected = lfc_ligand1 + lfc_ligand2,
      abs_additive = abs(lfc_additive_expected),
      lfc_total_interaction_model = lfc_additive_expected + lfc_interaction,
      interaction_score = lfc_interaction / lfc_total_interaction_model,
      source = source_label
    )
}

Real vs. null within each class

# oriented real - null: positive rank_biserial means real sits higher
source_summary <- function(df, value_col) {
  x <- df[[value_col]][df$source == "null"]
  y <- df[[value_col]][df$source == "real"]
  test <- suppressWarnings(wilcox.test(x, y))
  n1 <- length(x)
  n2 <- length(y)
  tibble(
    n_null = n1, n_real = n2,
    median_null = median(x, na.rm = TRUE), median_real = median(y, na.rm = TRUE),
    mean_null = mean(x, na.rm = TRUE), mean_real = mean(y, na.rm = TRUE),
    delta_mean = mean(y, na.rm = TRUE) - mean(x, na.rm = TRUE),
    p_value = test$p.value,
    # as.numeric() guards against 32-bit integer overflow in n1*n2
    rank_biserial = unname(1 - (2 * as.numeric(test$statistic)) / (as.numeric(n1) * as.numeric(n2)))
  )
}

# two-sample Kolmogorov-Smirnov on the same real-vs-null contrast.
# ks_D is the maximum vertical gap between the two ECDFs; ks_signed_D records
# where that gap sits, positive meaning real's ECDF runs above null's (real
# shifted toward LOWER percentiles), so it carries the direction that the
# two-sided D statistic discards.
ks_summary <- function(df, value_col) {
  x <- df[[value_col]][df$source == "null"]
  y <- df[[value_col]][df$source == "real"]
  test <- suppressWarnings(ks.test(y, x))
  grid <- sort(unique(c(x, y)))
  gap <- ecdf(y)(grid) - ecdf(x)(grid)
  tibble(
    ks_D = unname(test$statistic),
    ks_signed_D = gap[which.max(abs(gap))],
    ks_at_percentile = grid[which.max(abs(gap))],
    ks_p = test$p.value
  )
}
