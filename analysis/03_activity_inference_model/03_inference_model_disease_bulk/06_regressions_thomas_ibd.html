Goal

Test which SIG13 ligand activities differ in colonic CD4 T cells in UC and CD (Thomas et al. 2024), using the activity scores from 02_score_disease_datasets.py.

Model families, each fit across all conventional CD4 T cells and per celltype:

  1. Disease (pre-treatment only) – UC / CD / Healthy, pairwise
  2. Disease x remission (pre-treatment) – does baseline activity predict who later goes into remission?
  3. Vs healthy – every disease x remission x timepoint group against healthy
  4. Post vs pre treatment – within each disease x remission group
  5. Celltype – which activities distinguish CD4 subsets

All models adjust for sex and biopsy site and use HC3 robust covariance (patient numbers per group are uneven). Age is deliberately not a covariate: the healthy donors are much older than every patient group, so age is collinear with disease.

Import

IBD_KEYS <- c("Disease", "Patient", "Gender", "Remission_status", "Site",
              "Inflammation", "Treatment")

# The healthy donors carry placeholder metadata: no remission status and no
# timepoint (stored as the string "nan"). Renaming the timepoint to "None" gives
# the clean reference group label "Healthy_None_None" -- the old analysis used
# "Healthy_None _nan", the stray space coming from a trailing space in
# Remission_status that step 02 now strips at the source.
prepare_ibd <- function(df) {
  df %>%
    mutate(Treatment = ifelse(Treatment == "nan", "None", Treatment),
           disease_remission = paste(Disease, Remission_status, sep = "_"),
           disease_remission_treatment = paste(Disease, Remission_status, Treatment, sep = "_"),
           patient_site = paste(Patient, Site, sep = "_"),
           sex = factor(Gender),
           site = factor(Site),
           Disease = factor(Disease, c("UC", "CD", "Healthy")),
           Treatment = factor(Treatment, c("Pre", "Post", "None")))
}

ibd <- load_activity_scores("thomas_ibd", IBD_KEYS) %>% prepare_ibd()
ibd_celltype <- load_activity_scores("thomas_ibd_celltype", c(IBD_KEYS, "final_analysis")) %>%
  rename(celltype = final_analysis) %>%
  prepare_ibd() %>%
  mutate(celltype = fct_relevel(factor(celltype), "CD4 naive T"))

Age is strongly confounded with disease (healthy donors are older than all patient groups) and Batch partly so (all healthy donors are Batch 3) – neither is used as a covariate.

ibd %>%
  ggplot(aes(x = Inflammation, y = Inflammation_score, fill = Inflammation)) +

The paper filters IBD samples to molecular inflamed (Inflammation_score > 6.5, just above the healthy maximum) rather than trusting the histological call. That filter is available below but, is not applied – every model uses all samples.

Every group vs healthy

# healthy donors have no remission status or timepoint, so they are the single
# reference group; UC patients with unknown remission status are dropped
ibd_vs_healthy <- ibd %>%
  filter(Treatment %in% c("Pre", "Post") | Disease == "Healthy") %>%
  filter(Remission_status != "Not_avail" | Disease == "Healthy") %>%
  mutate(disease_remission_treatment = factor(disease_remission_treatment))

res_vs_healthy <- fit_and_save(
  ibd_vs_healthy,
  rhs = "disease_remission_treatment + sex + site",
  emm = ~ disease_remission_treatment,
  contrast_args = list(method = "trt.vs.ctrl", ref = "Healthy_None_None"),
  robust = TRUE,
  name = "thomas_ibd_disease_treatment_vsHealthy"
)
## thomas_ibd_disease_treatment_vsHealthy: 304 contrast x activity rows, 61 with padj < 0.1

Post vs pre treatment

ibd_paired <- ibd %>%
  filter(Treatment %in% c("Pre", "Post"), Remission_status != "Not_avail") %>%

res_treatment <- fit_and_save(
